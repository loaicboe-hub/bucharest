# دليل تشغيل الموقع بالكامل على استضافة هوستنجر (Hostinger)
### استضافة ذاتية 100% للصور وقاعدة البيانات

تم تجهيز هذا المجلد لتمكينك من تشغيل موقعك بالكامل (واجهة الموقع، لوحة تحكم الأدمن، رفع الصور، وقاعدة بيانات MySQL) مباشرة على استضافة **Hostinger Web Hosting** الخاصة بك دون أي خدمات سحابية خارجية أو مصاريف إضافية.

---

## محتويات هذا المجلد (`hostinger/`):

1. **`database.sql`**: ملف قاعدة البيانات الكامل (الجداول، الصلاحيات، الحسابات، البيانات الأولية).
2. **`api/`**: مجلد الـ API بلغة PHP الذي يعمل تلقائياً وبأعلى كفاءة على هوستنجر:
   - `config.php`: إعدادات الاتصال بقاعدة البيانات.
   - `auth.php`: نظام تسجيل دخول الأدمن وإدارة المستخدمين.
   - `products.php`: إدارة المنتجات وعرضها في الموقع.
   - `categories.php`: إدارة تصنيفات الفواكه والخضار.
   - `news.php`: المقالات والأخبار.
   - `partners.php`: شعارات الشركاء والمستوردين.
   - `settings.php`: بيانات التواصل والـ SEO ومواقع التواصل.
   - `quotes.php`: طلبات الأسعار المرسلة من العملاء.
   - `contacts.php`: رسائل صفحة اتصل بنا.
   - `invoices.php`: الفواتير التجارية.
   - `upload.php`: محرك رفع الصور والملفات المباشر على هوستنجر في مجلد `uploads/`.
3. **`.htaccess`**: ملف إعدادات سيرفر هوستنجر لتوجيه الروابط وتفعيل ضغط الملفات (Gzip) وتسريع تحميل الموقع.

## خطوات التثبيت في 4 خطوات بسيطة:

### الخطوة 1: إنشاء قاعدة بيانات MySQL في Hostinger
1. ادخل إلى حسابك في **Hostinger** وافتح لوحة التحكم (**hPanel**).
2. اضغط على **Websites** ثم اضغط على زر **Manage** بجوار موقعك.
3. من القائمة الجانبية، ابحث عن **Databases** واضغط على **MySQL Databases**.
4. قم بإنشاء قاعدة بيانات جديدة:
   - اكتب اسم قاعدة البيانات (مثال: `kemet`).
   - اكتب اسم المستخدم (مثال: `admin`).
   - اكتب كلمة مرور قوية واحفظها.
5. اضغط على **Create**.

---

### الخطوة 2: استيراد ملف `database.sql`
1. في نفس صفحة قواعد البيانات في هوستنجر، انزل للأسفل واضغط على زر **Enter phpMyAdmin** بجوار قاعدة البيانات التي أنشأتها.
2. من القائمة العلوية في phpMyAdmin، اضغط على تبويب **Import** (استيراد).
3. اضغط على **Choose File** واختر الملف [`hostinger/database.sql`](./database.sql).
4. انزل لأسفل واضغط على زر **Import** (أو **Go**).
   > ستظهر لك رسالة خضراء تفيد بنجاح استيراد 10 جداول بالكامل.

---

### الخطوة 3: تعديل بيانات الاتصال في `api/config.php`
افتح الملف [`hostinger/api/config.php`](./api/config.php) وعدّل السطور التالية ببيانات قاعدة البيانات التي أنشأتها في الخطوة 1:

```php
define('DB_HOST', 'localhost');          // اتركه كما هو localhost
define('DB_NAME', 'u123456789_kemet');     // ضع اسم قاعدة البيانات الكامل هنا
define('DB_USER', 'u123456789_admin');     // ضع اسم المستخدم هنا
define('DB_PASS', 'YourStrongPassword!');  // ضع كلمة المرور هنا
```

---

### الخطوة 4: رفع الملفات إلى `public_html` في هوستنجر
1. في لوحة التحكم **hPanel**، اضغط على **Files** ثم **File Manager**.
2. افتح مجلد **`public_html`**.
3. قم ببناء المشروع محلياً عبر تشغيل:
   ```bash
   npm run build
   ```
4. ارفع محتويات المجلد الناتج إلى داخل `public_html/`:
   - مجلد `assets/` وجميع ملفات الواجهة.
   - مجلد **`api/`** بالكامل (ليكون مساره: `public_html/api/`).
   - ملف **`.htaccess`** (ليكون في المسار الرئيسي: `public_html/.htaccess`).
   - أنشئ مجلداً فارغاً باسم **`uploads`** داخل `public_html/` وأعطه تصريح `755` أو `777` لتخزين الصور المرفوعة.

## بيانات الدخول الافتراضية للوحة التحكم (Admin):

* **رابط لوحة التحكم:** `https://yourdomain.com/admin/login`
* **البريد الإلكتروني:** `admin@bucharestegyagro.com`
* **كلمة المرور:** `AdminPassword2026!`

*(يمكنك تغيير كلمة المرور أو إنشاء حسابات مدراء إضافيين من شاشة إدارة المستخدمين في لوحة التحكم).*

---

## أين تذهب الصور المرفوعة؟
كل صورة يتم رفعها من لوحة التحكم (المنتجات، اللوجو، الشركاء، الأخبار، فيديو عن الشركة) تُحفظ مباشرة في استضافتك على هوستنجر داخل:
`public_html/uploads/...`
وتكون متاحة فوراً برابط مباشر وسريع.
